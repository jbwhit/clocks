**Files:**

- [ ] **Step 1: Write the page**

Frontmatter:

```yaml

title: "GPS in Reverse"

```

Content, in order:

1. **The hook (2 paragraphs).** GPS only works because the satellites' clocks are corrected for general relativity: gravitational time dilation makes their clocks run fast by about 45 microseconds per day, special relativity slows them by about 7, and the net ~38 µs/day would smear positions by kilometers within hours if uncorrected. So a clock's tick rate already encodes the gravitational potential it sits in. This site runs that logic backwards: scatter clocks through space, watch which ones tick slow, and infer where the hidden mass is and how heavy it is — a gravity detector made of nothing but timekeeping.
2. **Hero animation.** Embed: `![A particle filter localizing a hidden mass from clock rates alone](assets/demo_2d.gif)`
3. **One executed cell** showing the whole library round trip in ~10 lines (code-folded, deterministic):

```{{python}}
#| code-fold: true
import numpy as np
from clocks import (
    ClockArray, InferenceConfig, MassConfig, NoiseConfig,
    PriorConfig, SimulationConfig, infer, simulate,
)

clock_array = ClockArray(positions=np.array([[-5.0], [0.0], [5.0]]), track_offset=1.0)
truth = MassConfig(positions=np.array([[2.5]]), masses=np.array([0.8]))
sim = simulate(SimulationConfig(
    clock_array=clock_array, ground_truth=truth,
    noise=NoiseConfig(observation_std=0.005), n_observations=25, seed=42,
))
result = infer(sim.observations, InferenceConfig(
    clock_array=clock_array, noise=NoiseConfig(observation_std=0.005),
    prior=PriorConfig(position_range=(-8.0, 8.0), mass_range=(0.1, 2.0)),
    n_particles=400, n_masses=1, seed=42,
))
x, m = result.posterior_mean
sx, sm = result.posterior_std
print(f"Hidden mass: x = {x:.2f} ± {sx:.2f} (true 2.5)")
print(f"             M = {m:.2f} ± {sm:.2f} (true 0.8)")
```

```{{python}}
#| code-fold: true
#| fig-cap: "Tick rate vs distance from a point mass. Heavier masses dig deeper wells."
import matplotlib.pyplot as plt
import numpy as np
from clocks import ClockArray, MassConfig, clock_rates

fig, ax = plt.subplots()
distances = np.linspace(0.5, 10, 200)
for mass in (0.2, 0.5, 1.0):
    rates = [
        clock_rates(
            MassConfig(positions=np.array([[0.0]]), masses=np.array([mass])),
            ClockArray(positions=np.array([[d]])),
        )[0]
        for d in distances
    ]
    ax.plot(distances, rates, label=f"M = {mass}")
ax.set_xlabel("distance from mass")
ax.set_ylabel(r"tick rate $d\tau/dt$")
ax.legend()
fig
```

4. **Callout-note "The whole game"**: if you can measure tick rates precisely enough, every clock is a gravimeter; an array of them is a gravity *camera*. Foreshadow the next page's obstacle: one pixel is not a picture.

- [ ] **Step 1: Write the page**

Frontmatter: `title: "One Clock Is Not Enough"`. Sections:

1. **The degeneracy.** A single clock measures one number, Φ = −M/r, so every (M, r) pair with the same ratio is indistinguishable: a small nearby mass mimics a heavy distant one. This is the same mass–distance degeneracy that haunted the hunt for Neptune.
2. **Executed cell** — two visibly different mass configurations, identical single-clock reading:

near_light = MassConfig(positions=np.array([[2.0]]), masses=np.array([0.4]))

4. **Callout-note**: the noise floor matters — with observation noise σ the array distinguishes configurations only when their rate difference exceeds ~σ; that's why the demos feed the filter many noisy observations instead of one perfect one.

### Task 11: method/the-particle-filter.qmd

**Files:**
- Create: `site/method/the-particle-filter.qmd`

- [ ] **Step 1: Write the page**

Frontmatter: `title: "The Particle Filter"`. This page is for the reader who wants the mechanics. Sections:

1. **State.** N particles = N parameter hypotheses with weights summing to 1; initialized from the prior.
2. **Update.** Per observation: log-weight += Gaussian log-likelihood of observed rates given each particle's predicted rates (+ log-prior, −∞ outside bounds); normalize via log-sum-exp.
3. **Resampling.** ESS = 1/Σw²; below `resample_threshold · N`, resample (systematic/stratified/residual — one sentence each) and re-jitter. Jitter modes: fixed isotropic vs covariance-shaped (scaled Cholesky of the weighted empirical covariance), and why covariance jitter respects banana-shaped posteriors.
4. **Evidence.** Each update's increment is log Σᵢ wᵢLᵢ — the per-observation marginal likelihood; summed over observations it is the model's log-evidence, the quantity model comparison ranks.
5. **Executed cell** — ESS collapse and recovery: run the standard small 1D scenario via `build_particle_filter`, record `1/Σw²` after each of 25 updates, plot ESS vs observation number with the resample threshold as a dashed line, end with `fig`.
6. **Failure modes callout**: weight collapse (all-zero weights now raises `RuntimeError` instead of NaN), particle impoverishment, and the label-switching constraint from the multi-mass page.
